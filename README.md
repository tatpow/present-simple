## English

An agent skill for creating an introductory PowerPoint and a companion PDF you can read aloud. It proposes sources and visuals for your approval, then builds the deck and a slide-by-slide script. The PDF ends with questions, answers, and sources.

**Try it:** “Use `$present-simple` to make an introductory presentation on urban gardening for beginners.”

## Русский

Скилл для ознакомительной презентации PowerPoint и отдельного PDF для выступления. Сначала он предлагает источники и визуальные материалы на согласование. Затем собирает слайды и текст к каждому из них. В конце PDF — вопросы, ответы и источники.

**Пример:** «Используй `$present-simple` для презентации о городском садоводстве для начинающих».
